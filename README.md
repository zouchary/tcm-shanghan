# tcm-shanghan

中医伤寒杂病辨证论治技能 —— 六经辨证体系、80 首经方详解、11 则伤寒医案。

本仓库是一份可直接导入 AI Agent 技能库的中医知识工程 Skill：输入患者自述外感症状，输出六经归属、证型判断、方剂方案与针灸配穴。

## 核心内容

### 六经辨证体系

| 六经 | 病性 | 主症 | 治法 | 主方 |
|------|------|------|------|------|
| 太阳 | 表证 | 发热恶寒、头痛项强、脉浮 | 汗法 | 桂枝汤 / 麻黄汤 |
| 阳明 | 里热实证 | 但热不寒、大渴引饮、脉洪大；或腹满便秘、潮热谵语 | 清法 / 下法 | 白虎汤 / 三承气汤 |
| 少阳 | 半表半里 | 寒热往来、胸胁苦满、默默不欲饮食、脉弦 | 和法 | 小柴胡汤 |
| 太阴 | 里虚寒 | 腹满时痛、呕吐下利、自利不渴、脉沉弱 | 温法 | 理中汤 |
| 少阴 | 心肾阳虚 | 畏寒蜷卧、四肢厥冷、但欲寐、脉微细 | 温阳 / 滋阴 | 四逆汤 / 黄连阿胶汤 |
| 厥阴 | 寒热错杂 | 消渴、气上撞心、心中疼热、手足厥冷 | 寒热并调 | 乌梅丸 |

### 经方覆盖（80 首，按《伤寒论》条文顺序排列）

| 组别 | 数量 | 范围 |
|------|------|------|
| 太阳病本证 | 20 | 桂枝汤系（01–08）、麻黄汤系（09–15）、五苓散（16）、桂枝类变方（17–20） |
| 阳明热证 | 4 | 栀子豉汤、栀子厚朴汤、栀子干姜汤、枳实栀子豉汤（21–24） |
| 结胸证 | 5 | 大陷胸丸/汤、小陷胸汤、文蛤散、白散（25–29） |
| 痞证 | 8 | 三泻心汤、旋覆代赭汤、黄连汤、干姜附子汤（30–37） |
| 变证与差后 | 20 | 麻杏甘石汤至黄芩加半夏生姜汤（38–57） |
| 阳明腑证 | 13 | 白虎汤系、猪苓汤、竹叶石膏汤、三承气汤、茵陈蒿汤、栀子柏皮汤等（58–70） |
| 少阳与三阴 | 10 | 小柴胡汤、大柴胡汤、柴胡桂枝汤、理中汤、真武汤、乌梅丸、黄连阿胶汤、当归四逆汤类（71–80） |

### 医案（11 则）

外感实证 4 则（太阳伤寒、风寒两感、流感伤寒型、结胸变证）、经方验案 2 则（太阳经方、虚劳脉结代）、变证 1 则（痲证热痲）、阳明腑证 3 则（发黄、燥屎内结、蓄血善忘）、蓄血下焦 1 则（太阳蓄血）。

### 附子安全规范（`sources/08_附子安全规范.md`）

- **剂量梯度**：常规 15~30g 起始递增；急危重症 60~100g
- **煎法**：文火久煎 ≥1h，重剂 ≥2h，先煎久煎以去毒性
- **瞑眩 vs 中毒**：瞑眩（面色潮红、微微汗出、口麻）为正常药效；中毒先兆（口舌四肢麻木加剧、恶心呕吐、心律失常、血压下降）须立即停药就医
- **配伍禁忌**：不与半夏、瓜蒌、贝母、白蔹、白及同用（十八反）
- **须由有经验中医师辨证处方并指导**

## 使用方式

### 导入 AI Agent 技能库

将 `SKILL.md` 放入技能库目录，Agent 会依据 frontmatter 中的 `description` 自动匹配触发条件（用户自述发热/恶寒/头痛/咳嗽/咽痛等外感症状时触发）。

### 典型工作流

```
用户自述症状
  → 决策路由树（辨寒热 → 辨里虚寒 → 辨杂病 → 辨湿温）
    → 六经归属 + 证型
      → 查 modules/ 取方剂组成/加减/禁忌
        → 查 cases/ 找相似医案佐证
          → 按 SKILL.md「六、输出格式」输出
```

### 输出结构

技能规定了标准输出格式：六经归属 → 证型 → 症结所在 → 中药内服（方名/来源/组成/功效/用法）→ 针灸配穴 → 生活调摄 → 注意事项。

## ⚠️ 重要提示

本仓库为中医学习与知识工程参考，**不构成医疗建议**。

- 附子、乌头、大黄、芒硝、甘遂、水蛭、虻虫等峻攻破血毒烈之品，剂量与煎法关乎生命安全
- 四逆汤、承气汤、破格救心汤等峻剂**必须**在有经验中医师指导下使用
- 孕妇、儿童、老年人用药须特别注明并建议咨询专业医师
- 外感发热持续超过 3 天或高热不退，务必线下就医
- 本仓库内容依据公开文献整理，实际应用请以执业医师面诊为准
